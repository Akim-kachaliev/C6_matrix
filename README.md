# C6_matrix

Реализация библиотеки для работы с матрицами на C (C11, POSIX.1-2017).

Сборка
В корневой директории проекта (где находится src/):

Сборка статической библиотеки
make s21_matrix.a

Сборка и запуск тестов
make test

Генерация отчёта покрытия gcov (HTML)
make gcov_report

Очистка собранных файлов
make clean

Сборка всего (библиотека + тесты)
make all
Собранная библиотека: src/s21_matrix.a

# Структура матрицы
typedef struct matrix_struct {
    double** matrix;  // Указатель на массив строк
    int rows;         // Количество строк
    int columns;      // Количество столбцов
} s21_matrix;

Использование

#include "s21_matrix.h"

int main() {
    s21_matrix A, B, result;
    
    // Создание матриц
    s21_create_matrix(2, 2, &A);
    s21_create_matrix(2, 2, &B);
    
    // Заполнение
    A.matrix[0][0] = 1.0;
    A.matrix[0][1] = 2.0;
    A.matrix[1][0] = 3.0;
    A.matrix[1][1] = 4.0;
    
    B.matrix[0][0] = 5.0;
    B.matrix[0][1] = 6.0;
    B.matrix[1][0] = 7.0;
    B.matrix[1][1] = 8.0;
    
    // Сложение
    s21_sum_matrix(&A, &B, &result);
    
    // Транспонирование
    s21_transpose(&result, &result);
    
    // Определитель
    double det;
    s21_determinant(&result, &det);
    
    // Очистка
    s21_remove_matrix(&A);
    s21_remove_matrix(&B);
    s21_remove_matrix(&result);
    
    return 0;
}

# Примечания
Определитель вычисляется рекурсивно через разложение по первой строке

Матрица алгебраических дополнений использует создание миноров

Обратная матрица вычисляется по формуле: A⁻¹ = (1/det) * (C^T), где C — матрица алгебраических дополнений

Все функции корректно обрабатывают матрицы размера 1×1
